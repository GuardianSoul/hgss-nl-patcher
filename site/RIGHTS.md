# Release rights and provenance

The patcher UI, CSS scenery and browser patch engine were made for this project.
The release ships no ROM, extracted sprite, original font, music or logo file.
The only in-page game icon is decoded locally from the user's supplied file.
ROM bytes are never uploaded. Generated patches are kept separate from source.

This does **not** establish a right to distribute the adapted game text or
localized game artwork. A translation can be an adaptation requiring permission.
The repository stays private; public hosting/release is not part of the current
work. Do not label a release “fully legal” without obtaining any necessary
rightsholder authorization and legal advice for the intended jurisdiction.

[Auteursrecht.nl — bewerken, vertalen, verfilmen](https://www.auteursrecht.nl/ik-wil-jouw-werk-gebruiken/Bewerken-vertalen-verfilmen)
explains the permission issue. [CJEU C-355/12](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=CELEX%3A62012CJ0355)
addresses technical protection for video games; the patcher adds no bypass of
cartridge/console protections. Owning a cartridge is not represented as a blanket
permission to redistribute games or derivative translations.

Official reference links in index.html are Nintendo's Dutch game page and Dutch
Pokéwalker brochure, the Pokémon Company's original game page and Dutch TCG rules.
They support reference terminology/context, not endorsement of this translation.
Reported episode/time references are explicitly identified as reported, not independently
confirmed. A fanwiki is a secondary lookup source, not an official dub transcript.
The release is a work version; translation coverage and final editorial approval
are different things. The build does not invent user approval or change human edits.
